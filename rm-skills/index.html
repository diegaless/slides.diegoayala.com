03 / De la práctica a la soltura

Una ruta para prepararte

Propuesta de entrenamiento

Cuatro pasos para practicar con intención. Los tiempos y actividades siguientes son una propuesta de aula; se ajustarán al formato regional cuando se conozca.

01

Diagnóstico · 60 min

Empieza con un reto real

Resuelve el palíndromo de 2023 siguiendo sus restricciones. Reserva los últimos 15 minutos para comprobar casos y explicar la diferencia entre tus dos métodos.

Entrega Código, casos de prueba y una nota con las dificultades encontradas.

Ir al enunciado ↗
02

Java · 2 sesiones de 90 min

Afianza datos y objetos

Crea un gestor de préstamos de material: altas, búsqueda, préstamo, devolución y guardado en un fichero. Usa clases, colecciones y excepciones para entradas incorrectas.

Entrega Programa que conserva los datos al reiniciar y pruebas de errores, duplicados y disponibilidad.

Repasar Java ↗
03

Web · 3 sesiones de 2 h

Construye de principio a fin

Transforma ese gestor en una web: diseña las pantallas y la base de datos, crea una API y conecta la interfaz. Practica con PHP, SQL, HTML, CSS y JavaScript como preparación para las pruebas nacionales.

Entrega Aplicación funcional, datos de ejemplo e instrucciones para arrancarla desde cero.

Consultar documentación →
04

Simulacro · 3 h + 3 h 30 min

Ensaya con el reloj

Elige con el tutor un reto del archivo, comprueba primero que tienes sus materiales y trabaja con un tiempo cerrado. Anota bloqueos y deja una versión que se pueda ejecutar al terminar cada sesión.

Entrega Proyecto, evidencias de prueba y una revisión de lo que mejorarías. La duración toma 2025 como referencia.
