2025RMurciaSkills RegionalProgramación en JavaDescripción técnica · 6 h 30 min · 2 jornadas+

En el IES Ingeniero de la Cierva se planteaban programas Java con consola, ficheros, excepciones, estructuras de datos, clases, herencia e interfaces. Se valoraban la eficiencia, las pruebas y la documentación con Javadoc. El archivo oficial publica la descripción técnica; la casilla del test project no tiene descarga.

2023RMurciaSkills RegionalTres retos de programación en JavaTest project · Palíndromos, subconjuntos y listas+

2021RM Skills 2020 RegionalUna web con servidor de elección libreEdición celebrada en 2021 · Descripción técnica · 4 horas+

La edición denominada RM Skills 2020 se celebró en abril de 2021. En Desarrollo Web se pedía un sitio dinámico: base de datos, operaciones CRUD, autenticación, API, interfaz adaptable y acceso desde el cliente. El lenguaje de servidor y la base de datos eran de elección libre; se contemplaban HTML, CSS y JavaScript.
