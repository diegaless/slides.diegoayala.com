Corrección de un XML de planetas

Descarga el archivo HWGFW (1).xml de los materiales y corrígelo para que sea un documento XML bien formado.

Qué debes revisar

  • La sintaxis de las etiquetas y sus atributos.
  • La apertura, el cierre y el anidamiento de los elementos.
  • El uso de comillas en los valores de los atributos.
  • La existencia de un único elemento raíz.

Conserva los datos de los planetas del archivo original. El objetivo de esta tarea es corregir su estructura XML.

Entrega

Adjunta el archivo XML corregido.
