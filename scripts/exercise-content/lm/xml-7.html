Espacios de nombres: productos y clientes

Diseña un XML para un sistema que gestiona la información de los productos de un almacén y la de sus clientes.

  1. Incluye 3 productos y 3 clientes.
  2. Cada producto y cada cliente debe tener los atributos ID, nombre y estado.
  3. Define un espacio de nombres para los productos y otro para los clientes.
  4. Utiliza los espacios de nombres para diferenciar claramente ambos tipos de información.
  5. Comprueba que el XML esté bien formado.

Entrega

Adjunta el archivo XML.
