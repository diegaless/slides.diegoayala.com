Espacios de nombres: productos y expositores

Estás diseñando un sistema para una convención de tecnología. En ella se presentan productos tecnológicos y participan los expositores que los muestran.

Tanto los productos como los expositores tienen ID, nombre y descripción.

  1. Diseña un XML que represente únicamente esas características para cada producto y expositor.
  2. Define un espacio de nombres para los productos y otro diferente para los expositores.
  3. Usa esos espacios de nombres para distinguir las etiquetas que comparten el mismo nombre.
  4. Comprueba que el documento esté bien formado y que los prefijos estén declarados.
