COMPONENTE FORMULARIO

Instrucciones

  1. Entrada de Información Personal

    • Nombre: Campo de texto para el nombre completo del profesor.
      Número de Identificación: Campo de texto para el número de identificación personal (puede ser DNI, SSN, etc.).
      Datos de Contacto:
      • Email: Campo de texto para la dirección de correo electrónico.
        Teléfono: Campo de texto para el número de teléfono.
        Dirección: Campo de texto para la dirección postal.

    Información Académica y Profesional

    • Asignaturas: Campo de texto o lista desplegable para seleccionar las asignaturas que enseña.
      Titulación: Campo de texto o una lista desplegable para la titulación o grado académico.
      Experiencia: Área de texto para describir la experiencia docente o profesional relevante.

    Botones de Acción

    • Guardar: Botón para enviar y guardar la información.
      Limpiar: Botón para limpiar todos los campos del formulario.
      Cancelar: Botón para cerrar el formulario sin guardar cambios.
