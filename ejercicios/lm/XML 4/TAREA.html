XML 4

Instrucciones

Eres el administrador de sistemas de una universidad y deseas llevar un registro XML de las facultades, departamentos, carreras, cursos y estudiantes.
Define una estructura XML para representar la información de la universidad.

La universidad debe tener:

Facultades: Cada facultad tiene un nombre y un decano.
Departamentos: Dentro de cada facultad hay varios departamentos. Cada departamento tiene un nombre y un jefe de departamento.
Carreras: Dentro de cada departamento hay varias carreras. Cada carrera tiene un nombre, una duración (en años) y un coordinador.
Cursos: Cada carrera tiene varios cursos. Cada curso tiene un código, un nombre, un profesor y un semestre en el que se imparte.
Estudiantes: Cada curso tiene varios estudiantes inscritos. Cada estudiante tiene un código, un nombre y una fecha de nacimiento.

Crea un ejemplo con al menos:

2 facultades
1 departamento por facultad
1 carrera por departamento
2 cursos por carrera3 estudiantes por curso
