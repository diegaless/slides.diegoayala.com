LM 1DAW · Tarea

XML 5

Instrucciones

Eres el responsable de sistemas de un almacén que necesita diseñar un XML que almacene información sobre sus productos, ubicaciones, y proveedores.



El almacén debe tener:

Productos: Cada producto tiene un nombre, un código de producto, una categoría, un precio y una fecha de caducidad.
Ubicaciones: Cada producto está almacenado en una ubicación, que tiene un número de pasillo, un número de estante y una capacidad máxima.
Proveedores: Cada producto puede ser suministrado por varios proveedores, cada uno con un nombre, una dirección, y un número de teléfono.
Crea un ejemplo con al menos:

3 productos.
2 ubicaciones por producto.
2 proveedores por producto.
Objetivo: Diseñar un archivo XML bien estructurado que represente la gestión de un inventario en un almacén con productos, ubicaciones y proveedores.
